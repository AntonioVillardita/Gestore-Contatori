# Gestore Contatori

## Descrizione

Primo progetto della mia vita una volta entrato nel mondo del coding (Prima in Javascript e poi in Python).  
Progetto che nasce dall'esigenza di un amico, che in quanto proprietario di un negozio con sala LAN, aveva bisogno di qualcosa che lo aiutasse a gestire ogni situazione per cliente, in base al caso di utilizzo e al prezzo prestabilito, con Nome Cliente, Tempo trascorso ed un pannello di controllo con tasti compreso quello per calcolare il prezzo finale.

## Installazione

Scarica il Framework grafico moderno:  

```
pip install customtkinter
```
