# Gestore Contatori

## Descrizione

Primo progetto della mia vita una volta entrato nel mondo del coding (Prima in Javascript e poi in Python).
Progetto che nasce dall'esigenza di un amico, che in quanto proprietario di un negozio con sala LAN, aveva bisogno di qualcosa che lo aiutasse a gestire ogni situazione per cliente, in base al caso di utilizzo e al prezzo prestabilito, con "Nome Cliente", "Tempo trascorso" che cambia colore in base al tempo trascorso ed un pannello di controllo con tasti compreso quello per calcolare il prezzo finale.

## Installazione

**È richiesta la versione minima v3.7 di Python.**  
[Aggiorna](https://www.python.org/downloads/)

**Installa il Framework grafico moderno da terminale:**  

```
pip install customtkinter
```

**Se ce l'hai già, aggiornala con:**
```
pip install customtkinter --upgrade
```

**Installa anche la Libreria "Pillow" per inserire il Tuo logo:**
```
pip install pillow
```
